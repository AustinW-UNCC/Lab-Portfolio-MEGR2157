# A10 – RC2 Sliding Fit Resin Print

Objective - 

The main goal of this project was to get experience with the resin printers and learn how to use them just like we learned to use the 3D printers. Along with this, I was tasked with using knowledge from lecture and from previous projects to not only create a random item with the resin printers, but to create my own sliding fit and use my previous knowledge of fits to do so. 

1. Research and Planning - 

<img width="614" height="457" alt="image" src="https://github.com/user-attachments/assets/a06db9c5-c3a7-40d5-bd67-0aa3475d736f" />

RC2 fits are used primarily in cases where sliding or spinning parts need to interact with one another, but do not need to be going extremely fast or at very high rpms. They are primarily used for things like guiding shafts, alignment pins, optical focusing mechanisms, and machine tool components.

5. Fit Test -

My part was so hard to get together due to the shrinkage during the curing phase that I was unable to get the parts back apart without breaking them. This means that I could not mesaure the difference in the dimensions with the calipers for this part of the assignment. 

I showed the part to Dr. Fagan, and he saw that everything was done correctly besides some sort of miscalculation on the tolerance side. 

6. Lessons Learned -

The main challenge that arose in the RC2 fit was that an RC2 fit is in my opinion, too tight for those resin printers to accurately represent. Curing seemed to affect the fit the most because I was able to get the parts together prior to the curing process with much more ease. To improve accuracy next time, I will allow more space for tolerance to ensure that the parts will be able to fit together more properly. 

I spent about 5-6 hours total working on this project.
