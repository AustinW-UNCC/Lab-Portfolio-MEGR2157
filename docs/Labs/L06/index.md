# A6 – [Design Fits for an Artifact]

For this assignment, I was tasked with designing a piece that would snap fit onto another piece. I was given a stepper motor and free reign to design as I pleased. I decided to make a piece that would snap onto the bottom of the motor as there was a flat area on the underneath that would allow for me to print the object easier when that step came along. 11

Parametrically Design - 

The first step of the parametric design was to come up with an idea for what exactly I wanted to do. This step included visualizing how I wanted to start the design process in order to start in the right direction. 

The parameters used in this project start with the arms that wrap around the lip of the motor. These parameters are required because I need the shape to stay the same overall size in case I need to make changes to the design if the first one does not fit properly. 

Here is the list of parameters I started with on this project. Since no one piece depended on another for its' size, I was able to just identify each variable as what I measured them to be using the dial calipers. 

<img width="523" height="89" alt="image" src="https://github.com/user-attachments/assets/90bb9b90-e593-4583-9ffd-e61fa711d33b" />

I chose these parameters because the overall design of the snap fit was relatively simple and straight forward and required no directive measurements. 

  - For these parameters, I chose:
  
    - Base - 2.2in

    - Arm height - 0.4in

    - lip depth - 0.04in

    - Thickness - 0.1in

These values did change throughout the process because the first design I made was too small to get the arms around the whole motor. I had to change the size of the base 3 different times until I got it right because even with the calipers, it took some experimenting to get used to the extra depth needed for the arms and the lip of each snap fit piece. I also made slight changes to the arm length as I saw on my first attempt that the arms fit, but they were slightly too short to fully grip the lips of the motor. I changed those lengths by a few thousandths, and they fit great on the second attempt. 

The measurement part of the design came much earlier for me as I used the given data of the artifact to help proceed with my design instead of designing first without having proper numbers in mind. The best part about this was measuring the pieces while also starting the design. I believe that this helped me understand each design step much better and allowed for immediate change when necessary, in the design process.

Documentation - 

I used machine #02 for my prints because I wanted to try again using PETG and this machine was open and ready to go when I went to print my items. '

The print is only about 1.75 inches square and 0.5 inches tall. 

The layout process was easy because that was a major factor in my decisions when designing the part. I left the bottom flat so that it had a good base to sit on while printing. 

<img width="410" height="326" alt="Screenshot 2026-09-22 140615" src="https://github.com/user-attachments/assets/1b2c1a45-cff2-46aa-98c3-9b148673cdb7" />

The main reason for my build orientation was to use the bottom of the motor which was relatively flat to make my print easier to lay out in the slicer. 

The supports I used in this process may not have been necessary due to the lip pieces only being small overhangs, however, I wanted to use them just in case and the auto support feature did a great job covering that for me. 

The wall thickness was 0.1 inches throughout the print

There are 81 layers in this print with a layer thickness of 0.5mm to 0.7mm 

The build volume is 0.32

The slicer settings were kept to basic settings except I changed the brim thickness as seen below because I noticed that it helps with getting PETG off the printing plate when the piece is done. 

<img width="687" height="558" alt="image" src="https://github.com/user-attachments/assets/9cef3ff5-62f3-4039-8c91-43eccca5b1bb" />

To remove the supports, I used a pair of pliers that I found in the additive manufacturing lab. I believe that these worked well because I got the prints off of the printer while they were still hot. This helps when removing pieces that may get stuck on after the material cools down. 

The fit was not originally perfect; however I modified the size of the base design and the height of the arms on the piece to make them fit on my second and 3rd attempts. 

Show and Tell - 

The snap fit does work as wanted by the project guidelines and it is not easy to take off like the project requests.

Lessons Learned - 

This project helped me to learn a handful of things about design from allowing for extra space when having to account for the thickness of the arms while designing the base in order to make sure that you have enough tightness while also not breaking the part. I also learned how to better use relations in SolidWorks because the actual shape of the arms was dependent on them all being symmetrical. As much as that last step was difficult to figure out, I did enjoy learning how the program reads relations and why some relations do not do what you want them to.  

This project took about 4 hours total since I had to print my item 3 times to make it work.
