# A9 – Laser Cutter

For this lab I was tasked with working with a group to create a system of parts that fit together using only press fit techniques. To accomplish this, I had to measure the kerf from the machine and determine what size to make each slot to ensure tight fitment without the parts falling off or coming apart. This assignment was a lot of fun and I was very happy with the final outcome.
